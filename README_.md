# AI Chatbot 🤖

AI Chatbot is a Python-based conversational application designed to interact with users in natural language. It leverages modern AI models to understand user queries, generate intelligent responses, and provide an engaging conversational experience through a simple and intuitive interface.

This project is developed as an academic/learning project to demonstrate practical applications of Artificial Intelligence and Natural Language Processing.

---

## ✨ Features

- 💬 Natural language conversation  
- 🧠 Context-aware responses  
- ⚡ Fast and interactive UI  
- 🔒 Secure API-based AI integration  
- 🌐 Web-based interface using Streamlit  

---

## 🛠️ Tech Stack

- Python  
- Streamlit  
- Google Gemini API  
- Natural Language Processing (NLP)  
- HTML/CSS (for UI styling)

## ▶️ How to Run Locally

1. Clone the repository  
   git clone <your-repo-url>  
   cd ai-chatbot  

2. Install dependencies  
   pip install -r requirements.txt  

3. Add your API key  
   Open chatbot.py and paste your API key:
   
   GOOGLE_API_KEY = "YOUR_API_KEY_HERE"

4. Run the chatbot  
   streamlit run app.py
